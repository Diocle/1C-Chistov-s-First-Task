# Задача №1 — Учет товаров и контроль остатков

Учебная задача из сборника по разработке на платформе 1С Павла Чистова.

## Условие задачи

Необходимо разработать конфигурацию для учета товаров.

Многоскладской учет, суммовой учет и взаиморасчеты с покупателями и поставщиками не ведутся.

В системе необходимо регистрировать два вида операций:
- поступление товара;
- продажа товара.

При поступлении пользователь указывает в табличной части товары и их количество.

При продаже указывается, какие товары и в каком количестве проданы. Продажа товара в минус запрещена — при проведении необходимо проверить остаток товара.

Необходимо построить отчет по остаткам товаров на указанную пользователем дату.

Отчет должен формироваться на конец дня, включая документы, записанные на последнюю секунду выбранного дня.


В репозитории представлены два варианта решения данной задачи:

## 1) Новая методика

Сначала идет запись в БД, а потом проверка на отрицательный остаток.

## 2) Старая методика

Сначала выполняется проверка на отрицательный остаток, а затем формируются движения документа.
При перепроведении сначала записываются текущие движения документа, чтобы при проверке остатков не учитывались его старые движения.
