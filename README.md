# Учет товаров и контроль остатков в 1С

**Первая задача из сборника практических задач по 1С.**

Учебный проект на 1С:Предприятие.

**Решение выполнено по новой методике.**

## Условие задачи

> **Задача № 1**
> Самая простая задача
> Сложность: *
> Теги: регистры накопления
>
> ЗАКАЗЧИК просит разработать конфигурацию для учета товаров.
>
> Многоскладской учет не ведется. Суммовой учет не ведется. Взаиморасчеты с покупателями и поставщиками не ведутся.
>
> В системе необходимо регистрировать два вида операций:
>
> * Поступление товара;
> * Продажа товара.
>
> При поступлении товара пользователь в табличной части указывает, какие товары и в каком количестве поступили. Необходимо предусмотреть учет до граммов.
>
> При продаже товаров указывается, какие товары были проданы и в каком количестве.
>
> Продать товар «в минус» нельзя, в момент продажи необходимо проверять остаток товара.
>
> Необходимо построить отчет по остаткам товаров.
>
> Отчет строится на конец дня, указанного пользователем. Особое внимание следует уделить последней секунде дня: документы, записанные на эту секунду, должны попадать в отчет.

## Реализовано

* регистр накопления для учета остатков товаров;
* документы ПоступлениеТовара и ПродажаТовара;
* проведение документов и формирование движений;
* учет количества товаров с точностью до граммов;
* проверка отрицательных остатков при проведении продажи;
* запрет проведения документа при недостаточном количестве товара;
* вывод пользователю информации о недостающем количестве;
* использование временной таблицы для обработки данных табличной части;
* группировка товаров при обработке табличной части;
* получение остатков через виртуальную таблицу регистра накопления;
* проверка остатков на момент проведения документа;
* учет последней секунды выбранного дня при формировании отчета.
